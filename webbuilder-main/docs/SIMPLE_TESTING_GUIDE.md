## 🤔 What Is This Product?

### Simple Explanation

**EVI Web Builder** is like a **magic app maker**. You just tell it what you want in plain English, and it builds a working website or game for you!

Think of it like this:
- 📝 **You type:** "Make me a Sudoku game"
- 🤖 **AI works:** Creates all the code automatically
- 🎮 **You get:** A real, playable game with a link to share!

### What Can It Build?

| You Say... | You Get... |
|------------|------------|
| "Make a calculator" | ✅ Working calculator app |
| "Build a Sudoku game" | ✅ Playable puzzle game |
| "Create a to-do list" | ✅ Task management app |
| "Make a crypto wallet app" | ✅ Web3 app with wallet connect |

### Who Uses This?

- People who want apps but can't code
- Developers who want to save time
- Anyone who has an app idea!

## 📱 How to Use the App (Step by Step)

### Step 1: Open the Website

1. Go to **http://evi-web-lovat.vercel.app**
2. You'll see a login page

### Step 2: Sign In

1. Click **"Sign In"** button (top right corner)
2. Choose **Google** or **GitHub** to login
3. Allow permissions if asked

### Step 3: Start a New Project

1. Click the **"+"** button or **"New Chat"**
2. You'll see a chat box (like WhatsApp or ChatGPT)

### Step 4: Type What You Want

Type your request in simple English. Example:

```
Build a Sudoku puzzle game that works on mobile phones.
Make it colorful with easy, medium, and hard levels.
Add a timer to track how fast I solve it.
```

### Step 5: Click Send & Wait

1. Press **Enter** or click **Send** button
2. **Wait 3-5 minutes** ⏳
3. Watch the magic happen!

### Step 6: Get Your App!

1. You'll see a **link** when it's done
2. Click the link to open your new app
3. Share it with anyone! 🎉

When you send your request, you'll see these messages (in order):

| What You See | What's Happening | Wait Time |
|--------------|------------------|-----------|
| 🚀 "Starting..." | App is waking up | 2 seconds |

| 📋 "Planning..." | AI is planning the app | 20 seconds |
| 🔨 "Building..." | AI is creating files | 2-3 minutes |
| ✅ "Checking..." | Making sure it works | 30 seconds |

| 🎉 "Done!" + Link | Your app is ready! | - |

### ⏱️ Total Wait Time

| Type of App | How Long to Wait |
|-------------|------------------|
| Simple app (calculator) | 2-3 minutes |
| Game (Sudoku) | 3-5 minutes |

## 🔴 Common Problems & What to Do

### Problem 1: Page Won't Load

**What you see:** Blank white screen or error

**What to do:**
1. Refresh the page (F5 or pull down on phone)
2. Check your internet connection
3. Try a different browser (Chrome is best)

---

### Problem 2: Login Doesn't Work

**What you see:** Error after clicking Google/GitHub

**What to do:**
1. Try the other login option
2. Clear browser cache
3. Try incognito/private mode

---

### Problem 3: AI Gets Stuck

**What you see:** No new messages for 3+ minutes

**What to do:**
1. Wait a bit longer (some apps take time)
2. Refresh the page
3. Start a new chat and try again

---

### Problem 4: App Link Doesn't Work

**What you see:** Error when clicking the final link

**What to do:**
1. Wait 1 minute and try again
2. Copy the link and paste in new tab
3. Report this bug with screenshot

---

### Problem 5: App Looks Broken

**What you see:** Buttons overlapping, text cut off

**What to do:**
1. Try different screen size
2. Rotate phone (portrait/landscape)
3. Report with screenshot
